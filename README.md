## 🚀 Deployment Instructions

### Option 1: GitHub Pages (Recommended)

1. **Initialize Git Repository**
```bash
cd c:\Users\adity\Desktop\web-dev
git init
git add .
git commit -m "Initial commit: Add website templates"
```

2. **Create GitHub Repository**
   - Go to [GitHub](https://github.com) and create a new repository
   - Name it something like `web-templates` or `website-templates`
   - Don't initialize with README (we already have one)

3. **Push to GitHub**
```bash
git remote add origin https://github.com/YOUR-USERNAME/REPO-NAME.git
git branch -M main
git push -u origin main
```

4. **Enable GitHub Pages**
   - Go to your repository on GitHub
   - Click **Settings** → **Pages**
   - Under "Source", select **main** branch
   - Click **Save**
   - Your site will be live at: `https://YOUR-USERNAME.github.io/REPO-NAME/`

5. **Share Individual Template Links**
   - Hospital: `https://YOUR-USERNAME.github.io/REPO-NAME/hospital-website/`
   - Salon: `https://YOUR-USERNAME.github.io/REPO-NAME/salon-website/`
   - Electronics: `https://YOUR-USERNAME.github.io/REPO-NAME/electronics-shop/`
   - Grocery: `https://YOUR-USERNAME.github.io/REPO-NAME/grocery-market/`

---

### Option 2: Netlify (Alternative)

1. **Deploy with Netlify**
   - Go to [Netlify](https://www.netlify.com)
   - Drag and drop the `web-dev` folder
   - Get instant deployment with custom URL

2. **Share Links**
   - Portfolio: `https://your-site.netlify.app/`
   - Individual templates: `https://your-site.netlify.app/hospital-website/`

---

### Option 3: Vercel

1. **Install Vercel CLI**
```bash
npm install -g vercel
```

2. **Deploy**
```bash
cd c:\Users\adity\Desktop\web-dev
vercel
```

3. **Follow prompts** and get your live URL
